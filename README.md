# Gambit Daily Brief

桌游、TCG 与收藏卡行业资讯的静态每日简报。

## 内容

- 每日重点与分类资讯
- 原始来源、地区、发布日期与事件日期
- 按日期保存历史简报
- 事实与经营建议分开展示

## 发布

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## 更新

`data.json` 保存全部期刊。添加新的 `issues[YYYY-MM-DD]` 并更新 `latestIssue`，保留此前期刊。日常更新须校验字段和 HTTPS 来源链接。没有新一期时，不应把旧期标为当日内容。

本站仅整理公开资讯，标明核验范围；发售与赛事安排以相关官方最新公告为准。
